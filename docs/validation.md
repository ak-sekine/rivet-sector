- 入力アダプター：縦画面での有効化、部品外のキャプチャ、独立した指の解除、短い回避タップ、キャンセル、キャプチャ喪失、blur・pagehide・resize・visibilitychange、タッチ対応PCのマウス・キーボードを検証。

## 実機未検証

iPhone Safari・Android Chrome実機での3本指の持ちやすさ、指の遮蔽、Safariアドレスバーの伸縮、ノッチとホームインジケーター、ホーム画面への追加とstandalone起動、回転、画面ロック・通話・アプリ切替からの復帰、音声の聴感、発熱・FPS・電池消費は未確認。
Safe AreaはCSSで上下左右を考慮し、ブラウザでは同等のpaddingを人工的に与えて領域計算を検証する。実際の端末のenv値と動的表示は実機で確認が必要。
iOSの方向固定は保証しない。既に追加済みのPWAでは古いManifest設定が残る可能性があり、再追加時も確認する。

## 公開確認の制約

実行環境から `ak-sekine.github.io` へのHTTPSはプロキシのポリシーで403。公開サイト上での起動・素材HTTP応答・本番HTMLの一致は直接確認できない。
GitHub ActionsはGitHub連携で確認する。ローカルの成功を公開サイトの検証成功とは扱わない。
