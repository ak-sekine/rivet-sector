# Rivet Sector — 2Dシューティング試作

## 目的と構成

スマートフォンの見下ろし型2Dアクションシューティングの操作感と、Codexがコードだけで制作する
グラフィック・効果音・BGMの品質を、短時間で評価するための訓練エリア。
今後はPhaserの見下ろし型2Dアクションシューティングとして開発する。
正式URLは https://ak-sekine.github.io/rivet-sector/ 。旧 `/2d/` は正式URLへ転送する。
3D描画・操作・依存は廃止した。既存の2Dゲーム内容と素材は維持する。

- 描画：Phaser **4.2.1**（npmの固定バージョン、[公式リリース](https://phaser.io/download/release/v4.2.1)）。
- TypeScript、Vite **8.3.4**、Vitest **5.0.3**、GitHub Pagesを継続。
- `index.html` が2D本体、`2d/index.html` は旧URL転送専用。Pages baseは `/rivet-sector/`。
- `src/prototype2d/logic.ts`：DOM・Phaserに依存しない移動・回避・弾丸・衝突判定。
- `stage.ts`：描画と衝突が共有する寸法。`input.ts`：入力状態とDOMアダプター。
- `scene.ts`：Phaser描画・追従カメラ・演出・HUD。`audio.ts`：失敗を隔離するWeb Audioアダプター。
- 画像・音声はすべてGit管理し、Pagesと同じサイトから取得する。外部素材・CDN・素材サービスを使わない。

## 操作

| 環境 | 移動 | 照準・射撃 | 回避 | 音声 |
| --- | --- | --- | --- | --- |
| PC | WASD | マウス照準、左ボタン長押しで連射 | Space、押し直しで再回避 | Mまたは右上ボタン |
| スマートフォン | 左スティック、8方向 | 右スティック、360度。倒している間に連射 | 中央の独立ボタン | 右上ボタン |

スティックのデッドゾーンは可動半径の20%。左入力は最も近い45度方向へ丸め、長さ1へ正規化する。
指を離すと移動・射撃を停止する。各部品が独立したpointerIdを保持し、別の指に所有権を移さない。
移動・射撃・回避の3本指同時操作に対応する。Phaserは `input.activePointers: 3` を明示し、
UIのPointer Eventsも各操作のキャプチャ・キャンセル・キャプチャ喪失を処理する。
縦画面を標準とし、上から58pxのHUD、残りの高さを使うゲーム描画領域、独立した操作パネルを配置する。
ゲーム画面には操作説明やタッチ部品を重ねない。パネルは左右のスティックと中央60×64pxの回避をGridで分離する。
320px幅では左右106pxのスティックと12pxの間隔を確保する。パネル上下の余白は22px・30px。
PCは最大480px幅の縦長表示を中央に置く。`any-pointer: coarse` があればタッチパネルも使用可能。
キーボード・マウス入力はタッチ能力の有無で無効にしない。

`100dvh` と上下左右のSafe Areaを親コンテナのpaddingで確保し、その内側の残り高さをFlexboxで配分する。
ResizeObserverでゲーム領域の実寸をPhaserに渡す。画面全体の寸法は描画寸法として使わない。
ズームは `clamp(1, 描画幅/320, 2)`、指定の縦画面では横方向320ワールドpxを確保する。
Nearestフィルターとピクセル描画を維持する。キャラクターは幅320pxで32px、幅430pxで約43px。
タッチ可能な画面が幅280px未満または高さ440px未満なら、縮小せず表示拡大・縦向き利用を案内してゲーム時間を止める。
通常の縦画面で回転を要求しない。PC横長ウィンドウは妨げない。
操作はPointer Captureで部品の外まで追跡する。blur・visibilitychange・pagehide・resizeで入力を解除する。
ブラウザのスクロール・ズーム・長押しメニューを抑制する。

PWAはstart_url・scopeとも `/rivet-sector/`、displayはstandalone、orientationはportrait。
iOSではManifestによる完全な方向固定を保証しない。既存アイコンを維持し、オフラインキャッシュは追加しない。

## 実装したゲーム範囲

1280×768px、32pxタイルの緑色モノクロSF施設。壁と5か所の障害物、静止訓練ロボット1体。
プレイヤーは(640,416)から開始、標的は(768,352)。カメラは描画幅に応じた倍率でプレイヤーを追う。
Nearestフィルター、`pixelArt`、`roundPixels`、CSSの `image-rendering: pixelated` を指定する。
プレイヤーは4方向×4フレームで歩き、停止時は対応する方向の先頭フレームを表示する。
標的は2フレームの待機表示。命中時は0.15秒発光し、6フレームの小さな爆発と命中数を表示する。

| 項目 | 暫定仕様 |
| --- | --- |
| 通常移動 | 144px/秒、半径10px。斜めでも同速。円対矩形、最大2pxの小刻み移動と壁沿いの滑り |
| 射撃 | 0.25秒間隔、弾薬無制限、スタミナ消費なし |
| 弾 | 480px/秒、寿命1.8秒、半径2px、方向固定の移動オブジェクト |
| 弾の衝突 | 線分対拡張矩形・円の最も早い接触。壁・障害物を貫通しない。銃口越しの遮蔽も防ぐため中心から発射 |
| 回避 | 80px / 0.20秒。移動方向へ8方向ステップ。入力なしなら最後の向きの反対。壁で停止し滑らない |
| スタミナ | 2Dロジックで管理：最大・初期100、消費25、0.5秒待機して毎秒40回復、回避中は回復しない |
| 入力競合 | 回避中も射撃可能。回避は押下の瞬間1回。動作中・不足時の入力を予約しない |
| 時間 | 描画とは独立した1/120秒の固定更新。復帰時は蓄積を消去。長い描画停止は1フレーム最大0.1秒に制限 |

フォーカス喪失・ページ非表示・ページ離脱・リサイズ時に入力と回避を解除する。
中断中はゲーム時間を進めず、スタミナ・回復待機・射撃待機を保持する。
無敵時間はない。標的にHP・破壊はなく、移動時には通過できる。

## グラフィック生成

`scripts/generate-2d-assets.ts` がNode標準機能だけでピクセル単位のRGBA描画とPNGのCRC／zlibエンコードを行う。
`src/prototype2d/palette.ts` の6色を生成処理とPhaser描画で共有する。
明るいプレイヤーと、幅広い肩・縦の胸部発光模様を持つ暗めの標的を形状と明暗で区別する。生成AI画像サービス・外部画像・フォント素材は使わない。

```sh
npm run generate:2d
```

Node 24推奨。生成先は `public/2d/assets/`。PNGは**8ファイル、合計32フレーム／画像**。

| ファイル | サイズ | 内容 |
| --- | --- | --- |
| player.png | 128×128 | 32×32、下・上・左・右の4行、各4フレーム（16） |
| enemy.png | 64×32 | 32×32、緑色訓練ロボットの待機2フレーム |
| floor.png | 32×32 | 繰り返し可能な床タイル1枚 |
| wall.png | 32×32 | 繰り返し可能な壁タイル1枚 |
| obstacle.png | 32×32 | 斜線・パネル付きの装甲コンテナ1枚 |
| energy.png | 16×8 | 緑色のエネルギー弾1枚 |
| impact.png | 192×32 | 32×32、小さな爆発6フレーム（全着弾が緑色） |
| afterimage.png | 128×32 | 32×32、4方向の透過ロボット残像4枚 |

床・壁以外は透過背景。Phaserの図形描画で訓練区画の線・照準・標的リングを加える。

## PCM音声生成

同じスクリプトで22,050Hz・モノラル・16bit PCMのWAV **5ファイル**を生成する。
正弦波・倍音を制限した矩形波風音色・固定シードの疑似乱数ノイズとアタック／リリースで合成。
クリッピングを避け、BGMは両端ゼロ、各音符はループ境界前にリリースを完了する。

| ファイル | 長さ | 用途・音色 |
| --- | --- | --- |
| shot.wav | 0.12秒 | 射撃、下降する電子レーザー |
| hit.wav | 0.16秒 | 標的命中、非整数倍周波数を混ぜた金属的衝撃 |
| explosion.wav | 0.24秒 | 標的・壁・障害物着弾、低音と減衰ノイズ |
| dodge.wav | 0.18秒 | 回避開始、上昇する電子音 |
| bgm.wav | 12秒 | 120BPM、6小節。チップ音のメロディ、ベース、キック・スネア・ハイハット |

音声は初回のキー・ポインター・音声ボタン操作で有効化し、BGMをループする。
BGMゲイン0.22、射撃0.35、命中／回避0.45、爆発0.18。最大16個の同時効果音に制限する。
右上ボタン／MでBGMと効果音をミュート。ページ非表示・pagehideでは停止とAudioContextの一時停止を行う。
表示復帰後はBGMを先頭から再開する。ブラウザが再開を拒否した場合は次のユーザー操作で再試行する。
音声API不在・ダウンロード失敗・デコード／再生失敗は個別に処理し、ゲーム操作を継続する。
`catalog.json` に全素材の寸法・フレーム数・PCM仕様・秒数を保存する。

## モノクログリーンCRT描画（2026-10-14）

背景 `#020b04`、床 `#0b1e10`、暗い装甲 `#174b24`、輪郭 `#2f9f48`、
発光 `#79ff91`、発光芯 `#caffcf`。CSSの同名カスタムプロパティもこの6色に対応する。
床は低コントラストのパネル継ぎ目、壁は緑の縁とスリット、コンテナは斜線と留め具で表す。
プレイヤーの頭部・武器・脚部、弾丸の透過ハロー、短い命中閃光と粒子を明るくする。
フレーム寸法・方向・枚数・演出時間、座標・衝突・入力・PCM音声は維持する。
Manifestとブラウザのテーマ背景も暗緑に統一し、既存アイコンは維持する。

CRTは独立した `src/prototype2d/crt.css` の静的な疑似要素だけで描画する。
薄い3px周期の水平走査線、周辺減光、極薄の縦テクスチャ、緑の内側グローをゲーム領域に限定する。
`--crt-scanline-opacity`、`--crt-vignette-opacity`、`--crt-glow-opacity` で調整し、
`#lab` に `data-crt="off"` を設定すれば無効化できる。設定用の新しい操作部品は追加しない。
`pointer-events: none` により入力を通し、Canvasへのブラー・フィルター・追加描画パス・点滅・揺れは使わない。
描画解像度、Nearest、58px HUD、PC中央480px、Safe Area、独立したタッチパネルは変更しない。
