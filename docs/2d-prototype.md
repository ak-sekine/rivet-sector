# Rivet Sector — 2Dシューティング試作

## 目的と構成

スマートフォンの見下ろし型2Dアクションシューティングの操作感と、Codexがコードだけで制作する
グラフィック・効果音・BGMの品質を、短時間で評価するための訓練エリア。
完成ゲームやTPSの置き換えではない。TPSのソース・Babylon.js・既存URL・Manifestを維持し、
公開ページを https://ak-sekine.github.io/rivet-sector/2d/ に追加する。

- 描画：Phaser **4.2.1**（npmの固定バージョン、[公式リリース](https://phaser.io/download/release/v4.2.1)）。
- TypeScript、Vite **8.3.4**、Vitest **5.0.3**、GitHub Pagesを継続。
- `2d/index.html` を既存Vite構成の2つ目の入力に設定し、`dist/2d/index.html` を出力。
- `src/prototype2d/logic.ts`：DOM・Phaserに依存しない移動・回避・弾丸・衝突判定。
- `stage.ts`：描画と衝突が共有する寸法。`input.ts`：入力状態とDOMアダプター。
- `scene.ts`：Phaser描画・追従カメラ・演出・HUD。`audio.ts`：失敗を隔離するWeb Audioアダプター。
- 画像・音声はすべてGit管理し、Pagesと同じサイトから取得する。外部素材・CDN・素材サービスを使わない。

## 操作

| 環境 | 移動 | 照準・射撃 | 回避 | 音声 |
| --- | --- | --- | --- | --- |
| PC | WASD | マウス照準、左ボタン長押しで連射 | Space、押し直しで再回避 | Mまたは右上ボタン |
| スマートフォン | 左スティック、8方向 | 右スティック、360度。倒している間に連射 | 右スティック左隣の独立ボタン | 右上ボタン |

スティックのデッドゾーンは可動半径の20%。左入力は最も近い45度方向へ丸め、長さ1へ正規化する。
指を離すと移動・射撃を停止する。各部品が独立したpointerIdを保持し、別の指に所有権を移さない。
移動・射撃・回避の3本指同時操作に対応する。Phaserは `input.activePointers: 3` を明示し、
UIのPointer Eventsも各操作のキャプチャ・キャンセル・キャプチャ喪失を処理する。
横画面を基本とし、タッチ端末の縦画面には回転案内を表示してゲーム時間を止める。
Safe Areaの上下左右を加算し、タッチ中のスクロール・ズーム・長押しメニューを抑制する。
方向の強制固定やFullscreen APIは使わない。

## 実装したゲーム範囲

1280×768px、32pxタイルの青緑色の暗いSF施設。壁と5か所の障害物、橙色の静止ロボット1体。
プレイヤーは(640,416)から開始、標的は(768,352)。カメラは2倍の整数拡大でプレイヤーを追う。
Nearestフィルター、`pixelArt`、`roundPixels`、CSSの `image-rendering: pixelated` を指定する。
プレイヤーは4方向×4フレームで歩き、停止時は対応する方向の先頭フレームを表示する。
標的は2フレームの待機表示。命中時は0.15秒発光し、6フレームの小さな爆発と命中数を表示する。

| 項目 | 暫定仕様 |
| --- | --- |
| 通常移動 | 144px/秒、半径10px。斜めでも同速。円対矩形、最大2pxの小刻み移動と壁沿いの滑り |
| 射撃 | 0.25秒間隔、弾薬無制限、スタミナ消費なし |
| 弾 | 480px/秒、寿命1.8秒、半径2px、方向固定の移動オブジェクト |
| 弾の衝突 | 線分対拡張矩形・円の最も早い接触。壁・障害物を貫通しない。銃口越しの遮蔽も防ぐため中心から発射 |
| 回避 | 80px / 0.20秒。移動方向へ8方向ステップ。入力なしなら最後の向きの反対。壁で停止し滑らない |
| スタミナ | TPSの定数を参照：最大・初期100、消費25、0.5秒待機して毎秒40回復、回避中は回復しない |
| 入力競合 | 回避中も射撃可能。回避は押下の瞬間1回。動作中・不足時の入力を予約しない |
| 時間 | 描画とは独立した1/120秒の固定更新。復帰時は蓄積を消去。長い描画停止は1フレーム最大0.1秒に制限 |

フォーカス喪失・ページ非表示・ページ離脱・リサイズ時に入力と回避を解除する。
中断中はゲーム時間を進めず、スタミナ・回復待機・射撃待機を保持する。
無敵時間はない。標的にHP・破壊はなく、移動時には通過できる。

## グラフィック生成

`scripts/generate-2d-assets.ts` がNode標準機能だけでピクセル単位のRGBA描画とPNGのCRC／zlibエンコードを行う。
同一パレットとロボット描画関数を全方向・フレームで共有する。色数を抑え、青緑のプレイヤーと
橙色の標的・注意帯を区別する。生成AI画像サービス・外部画像・フォント素材は使わない。

```sh
npm run generate:2d
```

Node 24推奨。生成先は `public/2d/assets/`。PNGは**8ファイル、合計32フレーム／画像**。

| ファイル | サイズ | 内容 |
| --- | --- | --- |
| player.png | 128×128 | 32×32、下・上・左・右の4行、各4フレーム（16） |
| enemy.png | 64×32 | 32×32、橙色訓練ロボットの待機2フレーム |
| floor.png | 32×32 | 繰り返し可能な床タイル1枚 |
| wall.png | 32×32 | 繰り返し可能な壁タイル1枚 |
| obstacle.png | 32×32 | 注意帯付きの装甲コンテナ1枚 |
| energy.png | 16×8 | 青緑のエネルギー弾1枚 |
| impact.png | 192×32 | 32×32、小さな爆発6フレーム（壁着弾時は青緑に着色） |
| afterimage.png | 128×32 | 32×32、4方向の透過ロボット残像4枚 |

床・壁以外は透過背景。Phaserの図形描画で訓練区画の線・照準・標的リングを加える。

## PCM音声生成

同じスクリプトで22,050Hz・モノラル・16bit PCMのWAV **5ファイル**を生成する。
正弦波・倍音を制限した矩形波風音色・固定シードの疑似乱数ノイズとアタック／リリースで合成。
クリッピングを避け、BGMは両端ゼロ、各音符はループ境界前にリリースを完了する。

| ファイル | 長さ | 用途・音色 |
| --- | --- | --- |
| shot.wav | 0.12秒 | 射撃、下降する電子レーザー |
| hit.wav | 0.16秒 | 標的命中、非整数倍周波数を混ぜた金属的衝撃 |
| explosion.wav | 0.24秒 | 標的・壁・障害物着弾、低音と減衰ノイズ |
| dodge.wav | 0.18秒 | 回避開始、上昇する電子音 |
| bgm.wav | 12秒 | 120BPM、6小節。チップ音のメロディ、ベース、キック・スネア・ハイハット |

音声は初回のキー・ポインター・音声ボタン操作で有効化し、BGMをループする。
BGMゲイン0.22、射撃0.35、命中／回避0.45、爆発0.18。最大16個の同時効果音に制限する。
右上ボタン／MでBGMと効果音をミュート。ページ非表示・pagehideでは停止とAudioContextの一時停止を行う。
表示復帰後はBGMを先頭から再開する。ブラウザが再開を拒否した場合は次のユーザー操作で再試行する。
音声API不在・ダウンロード失敗・デコード／再生失敗は個別に処理し、ゲーム操作を継続する。
`catalog.json` に全素材の寸法・フレーム数・PCM仕様・秒数を保存する。

## 検証

2026-10-12、Windows上のVitest／TypeScript／ViteとPlaywrightによるヘッドレスEdgeで実行。
ブラウザ自動テストはスマートフォンの実機テストではない。音声デコード・再生状態と波形を検証するが、
iPhoneスピーカーでの聴感や実機のループ品質は未検証。

- `npm test`：110件成功（TPSの既存回帰テストを維持）。8方向・斜め速度・30/60/144FPS・停止・壁と5障害物・
  壁沿いの移動・射撃間隔・弾の速度と寿命・標的／壁の最初の衝突・回避／スタミナ・同時入力・キャンセル・中断を検証。
- 素材テスト：PNG署名・寸法・RGBA・CRC・展開、フレーム数、PCMヘッダー・長さ・非無音・ピーク・境界を検証。
  全14ファイルを一時ディレクトリへ再生成してGit管理中の結果とバイト単位で一致。
- 本番パス：既存PWAテスト内でTPS／2DのHTML、Manifest、アイコン、全2D素材の本番コピーを検証。
- `npm run build`：TypeScript／Viteの複数ページビルド成功。PhaserとBabylonの各エントリにバンドルサイズの警告あり。
- `git diff --check`：成功。
- PCブラウザ：1280×720、WASD／停止、追従カメラ、マウス連射と命中、Space長押しの1回回避、
  初回音声有効化、5WAVデコード、BGM、M／ボタンのミュート、非表示時停止とゲーム時間停止を確認。
  可視性処理は合成visibilitychangeで検証。音声APIを無効にした場合も移動継続を確認。
- スマートフォン相当：844×390／667×375、操作部品の画面内配置、移動＋射撃、移動＋射撃＋回避の3本指、
  回避長押し、1本だけ離した際の他入力の継続、全指キャンセル、390×844の回転案内と時間停止を確認。
- `scripts/browser-check.cjs`：既存TPSのPC／タッチ／PWA／射撃／スタミナのブラウザ回帰検証を実行。

再現用コマンド（PlaywrightとEdgeが必要）：

```powershell
npm run preview -- --port 4174
# 別ターミナル
$env:TEST_BASE_URL = 'http://localhost:4174/rivet-sector/2d/'
# Playwrightが外部にある場合だけ $env:PLAYWRIGHT_MODULE = '.../playwright'
npm run check:2d
```

同じスクリプトは公開URLを `TEST_BASE_URL` に設定して実行できる。
`node scripts/check-2d-deploy.cjs` はローカルHEADに対応するPagesワークフローの成功、
公開TPS／2DのHTMLと `dist` の一致、既存PWAと全2D素材のHTTP 200・バイト一致を検証する。
スクリーンショットは `.cache/2d-pc.png`、`2d-mobile-landscape.png`、`2d-mobile-portrait.png`（Git対象外）。
開発者用 `window.rivet2d.snapshot()` は状態のコピーのみ返し、公開ビルドでも検証できる。

## スマートフォン実機で確認する項目

- iPhone Safari／Android Chromeで左右のスティックの大きさ・デッドゾーン・指の遮蔽・狙いやすさ。
- 3本指で移動・射撃・回避を同時に行う際の持ち方、回避ボタンの到達性、キャンセル・離す順序。
- ノッチ／ホームインジケーター／Safariのアドレスバーを含むSafe Areaと、横回転・画面サイズ変化。
- 初回操作後の音声開始、BGMの継ぎ目・音量バランス・各効果音の聴感、消音設定の挙動。
- アプリ切替・画面ロック・通話・復帰時の入力解除と音声停止／再開。
- フレームレート・発熱・電池消費。タッチ入力遅延と回避80px／0.20秒の操作感。
- PWAから2Dページに移動した際の横画面表示と操作。Manifestのstart_urlは従来のTPSページを維持する。

これらは今回のブラウザ自動テストで実機確認済みとはしない。
