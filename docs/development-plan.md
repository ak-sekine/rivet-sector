# 今後の開発方針

TPS基本操作としてボクセル風ロボット、TPS追従カメラ、PC・タッチ移動、平面衝突判定を実装。
外部モデル・画像素材は使用しない。詳細は[操作仕様](controls.md)を参照。

今後、以下を段階的に実装する。

1. ボクセル風プレイヤーモデル（実装済み）
2. TPS追従カメラ（実装済み）
3. PC・スマートフォンの移動操作（実装済み、iPhoneで速度6.0・感度0.010の操作感確認済み）
4. 8方向ステップ回避（スタミナ方式実装済み、iPhoneで基本動作確認済み）
5. 射撃・照準（エネルギー銃、中央レティクル、Hitscan、静止標的、命中演出を実装済み）
6. 敵ロボット（静止した訓練標的のみ実装済み）
7. 敵AI
8. ステージ・ゲームルール

ステップ回避はShift／右下ボタンで開始。移動入力をカメラ基準の8方向へ丸め、入力長0.2未満は後方。
暫定値は距離2.5・時間0.20秒、一定速度12.5。固定クールダウンは廃止。無敵時間・空中回避なし。
スタミナ最大・初期100、消費25、最後の消費から0.5秒待機して毎秒40回復。回避中は回復しない。
25以上あれば終了直後に方向を決め直して連続回避できる。不足入力は破棄し通常移動を継続。
上部ヘッダーに現在値／最大値と青緑バーを表示し、不足時は色を変更。回避ボタンも動作中・不足を表示。
回避中は方向と向きを固定し通常移動を停止、視点操作は継続。終了後は現在の入力で通常移動へ戻る。
共通衝突判定で遮られたら滑らず早期終了し、消費を返還せず追加消費しない。
長押し・連打・キーリピートを予約せず、再発動には離して再入力が必要。
中断時は回避・入力・姿勢を解除し、スタミナと残り回復待機時間を維持。中断中は回復せず、復帰後に再開する。
完全再読み込みは100から開始。スタミナ関連定数はcreateDodgeで管理し、DOM・Babylon.jsから独立。
詳細と調整用定数は[操作仕様](controls.md#8方向ステップ回避)を参照。

射撃は0.25秒間隔、射程60、1入力1発、弾薬無制限、リロード・スタミナ消費なし。
PCはPointer Lock取得後の左クリック／F、スマートフォンは回避ボタンの上の「射撃」。
画面中央レティクルから現在のカメラレイで照準点を求め、銃口からの別レイで壁・障害物・床による遮蔽を検査する。
カメラ更新後に判定し、回避中の射撃と4本指入力を許可。中断時は入力・演出を解除し時計を停止する。
右腕の直方体銃と高さ2の橙色静止標的を外部素材なしで生成。標的には移動衝突を追加しない。
命中発光0.15秒、射線・着弾光0.06秒。判定・時計・描画を分離し、エフェクトの蓄積を防ぐ。
敵AI・敵攻撃・HP・ダメージ・破壊・弾薬制限・リロード・武器切替・連射・ロックオン・エイムアシスト・音・勝敗は未実装。
射撃機能と4本指操作、PWAでの配置はiPhone Safari／Android Chrome実機未検証。詳細は[射撃仕様](controls.md#照準と射撃)を参照。
将来の物理演算にはHavok、敵AIの経路探索にはNavMeshを検討する。初期環境には導入しない。
ゲームロジック・入力・描画は機能追加に合わせて分離し、未実装機能のダミーは作らない。
