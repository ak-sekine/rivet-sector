# 今後の開発方針

TPS基本操作としてボクセル風ロボット、TPS追従カメラ、PC・タッチ移動、平面衝突判定を実装。
外部モデル・画像素材は使用しない。詳細は[操作仕様](controls.md)を参照。

今後、以下を段階的に実装する。

1. ボクセル風プレイヤーモデル（実装済み）
2. TPS追従カメラ（実装済み）
3. PC・スマートフォンの移動操作（実装済み、iPhoneで速度6.0・感度0.010の操作感確認済み）
4. 8方向ステップ回避（実装済み、回避の実機確認は別途必要）
5. 射撃・照準
6. 敵ロボット
7. 敵AI
8. ステージ・ゲームルール

ステップ回避はShift／右下ボタンで開始。移動入力をカメラ基準の8方向へ丸め、入力長0.2未満は後方。
暫定値は距離2.5・時間0.20秒・開始からクールダウン0.70秒、一定速度12.5。無敵時間・空中回避なし。
回避中は方向と向きを固定し通常移動を停止、視点操作は継続。終了後は現在の入力で通常移動へ戻る。
共通衝突判定で遮られたら滑らず早期終了し、クールダウンは維持する。
長押し・連打・キーリピートを予約せず、再発動には離して再入力が必要。
中断時は回避・入力・姿勢を解除し、残りクールダウンは中断中停止、復帰後に再開する。
詳細と調整用定数は[操作仕様](controls.md#8方向ステップ回避)を参照。
将来の物理演算にはHavok、敵AIの経路探索にはNavMeshを検討する。初期環境には導入しない。
ゲームロジック・入力・描画は機能追加に合わせて分離し、未実装機能のダミーは作らない。
