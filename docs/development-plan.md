# 今後の開発方針

初期段階ではWebGLによる静的シーンと開発確認用ArcRotateCameraのみを実装する。
この仮カメラはTPSカメラではない。外部モデル・画像素材は使用しない。

今後、以下を段階的に実装する。

1. ボクセル風プレイヤーモデル
2. TPS追従カメラ
3. PC・スマートフォンの移動操作
4. 8方向ステップ回避
5. 射撃・照準
6. 敵ロボット
7. 敵AI
8. ステージ・ゲームルール

ステップ回避は重要な操作として扱う。距離・速度・無敵時間などは今後検討し、現時点では確定しない。
将来の物理演算にはHavok、敵AIの経路探索にはNavMeshを検討する。初期環境には導入しない。
ゲームロジック・入力・描画は機能追加に合わせて分離し、未実装機能のダミーは作らない。
