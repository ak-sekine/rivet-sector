# TPS基本操作

PC：WASDで移動。画面クリックでPointer Lock、マウスで視点変更、Escで解除。
Pointer Lockが使用できない場合は左ボタンドラッグで視点を操作する。
スマートフォン：左下スティックで移動、その他の画面をスワイプして視点変更。
別々の指による同時操作に対応。横画面推奨、縦画面とSafe Areaにも対応。
Pointer Eventsとany-pointerで判定し、UAに依存しない。
フォーカス喪失、タブ切替、指のキャンセル時は入力を解除する。

## プレイヤーと移動

高さ2、足裏y=0、初期位置(0,0,-5)。全体TransformNode配下に部位別ジョイントを設ける。
頭・胴・腕・脚・足、前面バイザーと背面パック／ライトを直方体で生成する。
移動速度6単位/秒、半径0.48、旋回係数12。カメラ水平角基準、斜め入力は最大長1へ正規化。
水平円と静的AABBの最近点距離で判定し、床外周も制限する。
最大0.04単位の軸別小刻み移動で貫通を防ぎ、壁沿いに滑る。平坦ステージ専用。
描画と判定はsrc/stage.tsの寸法を共有する。壁がない2辺は移動境界として扱う。
フレーム時間最大0.05秒。非表示中は更新を止め、復帰時に時刻をリセットする。

## TPSカメラ

FreeCameraを右肩後方に配置。距離5、右肩0.75、注視高さ1.5、追従係数14。
上下角度-0.35〜1.1ラジアン、初期0.25。
PCマウス感度0.004、タッチ感度0.010ラジアン/ピクセル。
Pointer EventsのpointerTypeで区別し、Pointer LockとマウスドラッグにはPC感度を適用する。
入力側でピクセル差分を一度だけラジアンに変換し、lookX/lookYとしてカメラへ渡す。
カメラ側は角度を直接加算し、感度を再適用しない。
移動速度と感度は操作感検証用の暫定値で、今後調整する可能性がある。
PLAYER_SPEEDはsrc/game/movement.ts、MOUSE_SENSITIVITY／TOUCH_SENSITIVITYはsrc/game/view.tsで定数管理する。
カメラ水平角とプレイヤーの向きは独立。移動による自動回転はない。
プレイヤーから希望位置への中央と左右3本のレイで床・壁・障害物を検査し、
接触距離から0.25手前へ短縮する。プレイヤー自身は除外。
衝突短縮は即時、復帰は指数補間。near planeは0.05。
狭い場所ではカメラが近づき、プレイヤーが大きく映る場合がある。

## ホーム画面起動と画面方向

ホーム画面への追加方法は[README](../README.md#ホーム画面から起動pwa)を参照。
Manifestでスタンドアロン表示と横画面を希望する。方向固定・Fullscreen APIは使用しない。
iPhoneでは画面縦向きロックを解除して端末を横にする。縦画面では小さな横画面推奨文を表示する。
3Dキャンバスは動的ビューポート全体に表示し、スクロールを抑制する。
左下スティックはSafe Areaに追加の余白を設け、ノッチとホームインジケーターとの重なりを抑える。
通常ブラウザとスタンドアロンで入力・ゲーム処理は同一。SafariのUI非表示や回転はOS・ブラウザ次第で、実機確認が必要。
Service Workerとオフライン動作は導入しない。
