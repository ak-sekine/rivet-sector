# TPS基本操作

PC：WASDで移動。画面クリックでPointer Lock、マウスで視点変更、Escで解除。
Pointer Lockが使用できない場合は左ボタンドラッグで視点を操作する。
スマートフォン：左下スティックで移動、その他の画面をスワイプして視点変更。
別々の指による同時操作に対応。横画面推奨、縦画面とSafe Areaにも対応。
Pointer Eventsとany-pointerで判定し、UAに依存しない。
フォーカス喪失、タブ切替、指のキャンセル時は入力を解除する。

## プレイヤーと移動

高さ2、足裏y=0、初期位置(0,0,-5)。全体TransformNode配下に部位別ジョイントを設ける。
頭・胴・腕・脚・足、前面バイザーと背面パック／ライトを直方体で生成する。
移動速度6単位/秒、半径0.48、旋回係数12。カメラ水平角基準、斜め入力は最大長1へ正規化。
水平円と静的AABBの最近点距離で判定し、床外周も制限する。
最大0.04単位の軸別小刻み移動で貫通を防ぎ、壁沿いに滑る。平坦ステージ専用。
描画と判定はsrc/stage.tsの寸法を共有する。壁がない2辺は移動境界として扱う。
フレーム時間最大0.05秒。非表示中は更新を止め、復帰時に時刻をリセットする。

## TPSカメラ

FreeCameraを右肩後方に配置。距離5、右肩0.75、注視高さ1.5、追従係数14。
上下角度-0.35〜1.1ラジアン、初期0.25。
PCマウス感度0.004、タッチ感度0.010ラジアン/ピクセル。
Pointer EventsのpointerTypeで区別し、Pointer LockとマウスドラッグにはPC感度を適用する。
入力側でピクセル差分を一度だけラジアンに変換し、lookX/lookYとしてカメラへ渡す。
カメラ側は角度を直接加算し、感度を再適用しない。
移動速度と感度は操作感検証用の暫定値で、今後調整する可能性がある。
PLAYER_SPEEDはsrc/game/movement.ts、MOUSE_SENSITIVITY／TOUCH_SENSITIVITYはsrc/game/view.tsで定数管理する。
カメラ水平角とプレイヤーの向きは独立。移動による自動回転はない。
中央の射線を自分のモデルで隠さないよう、注視点は高さ1.5のプレイヤー位置から右肩側へ0.75ずらす。
プレイヤーから希望位置への中央と左右3本のレイで床・壁・障害物を検査し、
接触距離から0.25手前へ短縮する。プレイヤー自身は除外。
衝突短縮は即時、復帰は指数補間。near planeは0.05。
狭い場所ではカメラが近づき、プレイヤーが大きく映る場合がある。

## ホーム画面起動と画面方向

ホーム画面への追加方法は[README](../README.md#ホーム画面から起動pwa)を参照。
Manifestでスタンドアロン表示と横画面を希望する。方向固定・Fullscreen APIは使用しない。
iPhoneでは画面縦向きロックを解除して端末を横にする。縦画面では小さな横画面推奨文を表示する。
3Dキャンバスは動的ビューポート全体に表示し、スクロールを抑制する。
左下スティックはSafe Areaに追加の余白を設け、ノッチとホームインジケーターとの重なりを抑える。
通常ブラウザとスタンドアロンで入力・ゲーム処理は同一。SafariのUI非表示や回転はOS・ブラウザ次第で、実機確認が必要。
Service Workerとオフライン動作は導入しない。

## 8方向ステップ回避

PCはShift、タッチ端末は右下の「回避」を押す。移動入力をカメラ水平角基準で
最も近い45度単位の8方向へ変換する。入力長が0.2未満ならカメラ基準の後方。
距離2.5単位、時間0.20秒、速度12.5単位/秒。固定クールダウンは廃止。
スタミナは最大・初期100、開始時に25消費、毎秒40回復、最後の消費から0.5秒待機。
回避中は回復しない。待機をまたぐフレームでは待機終了後の時間だけ回復する。0〜100に制限する。
待機中でも25以上なら回避可能で、終了直後の新しい入力で方向を決め直し連続回避できる。
25未満の入力は消費せず破棄し、通常移動を妨げない。移動中・停止中も自動回復する。
数値は暫定値で、src/game/dodge.tsの定数で調整する。
通常速度6.0、PC感度0.004、タッチ感度0.010は維持する。

回避中は通常移動を停止し、開始時の世界方向とキャラクターの向きを固定する。
カメラ操作は継続でき、終了後は現在の移動入力に戻る。無敵時間はなく、空中では開始不可。
現在のステージは平坦で常時接地し、ジャンプは未実装。
最終フレームは残り時間で切り詰める。通常移動と共通の水平円対AABB・床外周判定、
最大0.04単位の小刻み移動を使用する。回避は斜めも一括で安全性を確認し、
遮られたら滑らず安全な位置で終了する。早期終了でも消費を返還せず、追加消費しない。

長押し・キーリピートは1回だけ。再発動は離して再入力が必要。
回避中・スタミナ不足時の入力は破棄し、予約しない。
ボタンは64×64 CSSピクセル、Safe Areaに余白を追加し、回避中と不足時の色を区別する。
上部の既存ヘッダーに青緑の横長スタミナバーと現在値／最大値を表示。不足時は色を変える。
PC・スマホ共通で、progressbarのラベルと現在値を設定する。Safe Areaは既存ヘッダーに従う。
Pointer Eventsの別々のpointerIdで移動・視点・回避を同時操作できる。
指のキャンセル／キャプチャ喪失は回避入力を解除する。胴体だけを軽く傾け、判定に影響させない。

フォーカス喪失・タブ切替・pagehide・Pointer Lock変更／Escで入力と進行中の回避・姿勢をリセットする。
非表示・フォーカス喪失中はゲーム時間を停止し、スタミナと残り回復待機時間を保持する。
復帰後に残り時間を進め、復帰直後の自動回避は行わない。フレーム時間上限0.05秒も維持する。
単体テストは8方向・固定方向・30/60FPS・衝突・長押し・中断を検証する。
既存の距離・速度・ボタン配置・3本指操作はユーザーがiPhoneで確認済み。
既存のスタミナ方式とゲージはユーザーがiPhoneで基本動作を確認済み。完全再読み込みでは100に戻る。

## 照準と射撃

青緑の小さな十字レティクルをキャンバス中央に固定。中央に隙間を設け、pointer-events:noneで入力を妨げない。
PCは最初の左クリックでPointer Lockを取得し、そのクリックでは発射しない。固定後の左クリックで1発。
Escで解除、マウス視点操作は維持。固定できない環境は左ドラッグで視点、Fで射撃する。
Fは固定中も使用可能。左ボタン・F・タッチボタンの長押しでは連射しない。
スマートフォンは右下の回避ボタンの80px上に64×64pxの円形「射撃」を配置（間隔16px）。
回避の位置・サイズは維持し、右・下のSafe Areaを加算。押下中と発射待機中の外観を変える。
any-pointerとPointer Eventsで表示・操作し、UA文字列は使用しない。

エネルギー銃1種類、発射間隔0.25秒、最大射程60ワールド単位。弾薬無制限、リロードなし、スタミナ消費なし。
入力は要求として保持し、更新ループで移動・回避とカメラを更新した後に処理する。
間隔中の入力は破棄し、後から発射しない。間隔と演出はゲーム内経過秒で管理し、setTimeoutは使わない。
射撃時計は既存の移動用0.05秒上限とは独立して実際のアクティブな経過時間を使用する。

カメラの現在のビュー行列を更新し、getForwardRayで画面中央と一致する60単位のレイを求める。
Babylon.jsのpickWithRayで標的・壁・障害物・床の最も手前の点を照準目標点とする。
何もなければカメラから60単位先を採用。次に右腕のmuzzle TransformNodeのワールド座標から目標点へレイを飛ばす。
銃口からも最大60単位に制限し、最初の表面で止める。銃口だけが壁に遮られる場合も標的へ命中させない。
カメラが狙った標的と異なる標的が銃口の射線に入っても標的命中扱いにしない。
射撃用shotSurface／targetIdとカメラ用cameraObstacleは別属性。自分・武器・HUD・演出は判定対象外。
結果は標的命中・表面着弾・ミスの3種類。移動衝突、カメラ位置調整の仕様は変更しない。

銃は右腕ジョイント配下の暗い金属色の本体・銃身・青緑発光アクセントの直方体モデル。
プレイヤーの移動・回転に追従し、銃口はmuzzleノードから取得する。武器には移動衝突を追加しない。
標的は(0,0,3)の橙色ロボット1体。頭・胴体・バイザー・両腕・両脚・両足を直方体で構成し、高さ2。
各部位はtraining-robotという共通targetIdを持つ。障害物には埋まらず、初期位置から少し視点を動かせば狙える。
静止・非攻撃・HPなし・破壊なし。標的のプレイヤー移動衝突は追加していないため通過できる。

標的命中時は専用マテリアルを0.15秒発光させ、その後元に戻す。再命中は発光時間を更新する。
銃口から終点への細い青緑線と、命中・着弾点の小さな光を0.06秒表示する。ミスには着弾光を出さない。
壁・床への着弾では標的は発光しない。光球は再利用し、線は終了・再発射時に破棄して蓄積を防ぐ。
判定はsrc/game/hitscan.ts、間隔はsrc/game/shooting.ts、標的と演出はsrc/rendering内で分離する。

移動・視点・回避・射撃は独立したpointerIdで同時操作できる。射撃ボタンのイベントは伝播させない。
回避中もその時点のカメラ中央に射撃でき、射撃によるスタミナ減少はない。
キャンセル・キャプチャ喪失で該当指の要求と押下表示を解除する。
blur・visibilitychange・pagehide・Pointer Lock変更／Escで要求と一時演出を解除。
中断中は射撃時計を進めず、残り発射待機を保持。復帰時に要求を予約せず、新しい入力が必要。
既存の回避・スタミナの中断処理は維持する。

敵AI、移動敵、敵攻撃、HP・ダメージ・破壊、弾薬制限、リロード、複数武器・切替、
自動連射、ロックオン、エイムアシスト、複雑な射撃アニメーション、音、ゲームオーバー・クリアは未実装。
射撃追加後のiPhone Safari／Android Chromeの実機操作、4本指、PWA起動・Safe Areaは未検証。
